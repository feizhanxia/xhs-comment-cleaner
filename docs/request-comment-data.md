# 向小红书申请评论数据副本 / 批量删除

网页端互动通知无法覆盖从未收到回复或点赞的评论。若要追求完整清理，可同时通过小红书 App 客服和隐私联系邮箱申请本人评论数据副本及批量删除。

建议先在 App 内联系人工客服，保留工单编号；如无法解决，再发送邮件至小红书用户隐私政策公布的联系邮箱 `shuduizhang@xiaohongshu.com`。该政策称会在验证身份后的十五个工作日内答复隐私问题。不要在公开 Issue 中提交手机号、身份证、Cookie 或验证码。

## 申请文本

```text
主题：申请查阅并删除本人账号历史评论数据

您好：

我是小红书账号【小红书号/账号昵称】的本人使用者。

由于客户端和网页端均未提供“我发出的全部评论”列表，我无法自行完整查阅和删除本人在其他用户笔记下发布的历史评论及回复。现申请：

1. 提供本人账号发布的全部评论和回复的数据副本；
2. 数据至少包含：评论 ID、所属笔记 ID 或可访问链接、评论正文、发布时间、删除状态；
3. 在完成身份核验后，协助批量删除上述仍对外展示的评论和回复；
4. 如无法提供或删除，请书面说明具体原因、缺失范围及可行的替代处理方式。

我愿意通过小红书官方渠道完成必要的身份核验，请告知安全的核验方式。请勿要求我通过非官方渠道发送密码、短信验证码或登录 Cookie。

谢谢。
```

收到平台导出的文件后，可在本项目新增导入适配器，将笔记 ID/链接和评论 ID 写入本地 SQLite，再沿用已有的账号归属复核与删除流程。
